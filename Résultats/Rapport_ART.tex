\section*{Introduction}
\addcontentsline{toc}{section}{Introduction}
\begin{spacing}{1.5}
\noindent
Nous avons identifié l'article \textit{« Augmenting brain-computer interfaces with
ART: An artifact removal transformer for reconstructing multichannel EEG
signals »} de Chuang \textit{et al.}, qui présente une nouvelle méthode de
débruitage appelée \textbf{ART} (\textit{Artifact Removal Transformer}) et montre
de bons résultats sur des données d'imagerie motrice (\textit{motor-imagery}).
Dans leur étude, les auteurs entraînent ART sur la base \textit{Eyes-Closed/
Eyes-Open Resting-State} (Chuang \textit{et al.}, 2022). Nous avons identifié une
limite à cette base pour l'entraînement : elle ne contient pas les artefacts
habituels d'une séance EEG, comme les clignements des yeux (\textit{blinks}).

\vspace{0.5em}
C'est ce qui motive notre choix d'utiliser la base \textbf{Schalk \textit{et al.}
(2004), Motor Imagery (BCI2000)}, et d'y entraîner ART en prenant comme signaux
propres ceux nettoyés par \textbf{ICLabel}. L'objectif est de tester si ART peut
apprendre à nettoyer automatiquement les signaux aussi bien, voire mieux,
qu'ICLabel.

\vspace{0.5em}
\noindent
Pour chaque sujet exclu (protocole leave-one-subject-out), ce document rapporte :
le taux de classification gauche/droite (CSP+LDA) sur les différents signaux
débruités disponibles (brut, ICA manuelle, ICLabel automatique, ART, ...) ;
l'erreur quadratique moyenne (MSE) entre le signal nettoyé par ICA et celui
nettoyé par ICLabel ; ainsi que l'évolution du MSE (train/eval) pendant
l'entraînement leave-one-subject-out d'ART.

\vspace{0.5em}
\noindent\textbf{Mots-clés :} EEG, BCI, ART, ICA, ICLabel, CSP, MSE, motor-imagery.
\end{spacing}

\section{Méthodologie}

\subsection{Taux de classification (CSP+LDA)}
Pour mesurer à quel point l'intention motrice (main gauche vs main droite) reste
lisible dans un signal après débruitage, on applique une chaîne de classification
standard en EEG : filtrage passe-bande dans la bande sensori-motrice (7--30~Hz),
extraction d'une courte fenêtre temporelle après le stimulus, puis un filtrage
spatial (CSP) qui recherche les directions de l'espace séparant le mieux les
deux classes. La variance du signal filtré sert ensuite de caractéristique à un
classifieur linéaire (LDA).

La précision rapportée est la proportion d'essais correctement classés,
\[
  \text{Précision} = \frac{\text{essais bien classés}}{\text{essais totaux}}\,,
\]
moyennée sur plusieurs tirages aléatoires indépendants d'entraînement/test
(80\,\%/20\,\%) pour lisser la variabilité d'un tirage à l'autre.

\subsection{MSE ICA vs ICLabel}
Pour comparer deux méthodes de débruitage entre elles, on calcule l'erreur
quadratique moyenne (MSE) entre les signaux nettoyés correspondants, essai par
essai :
\[
  \text{MSE} = \frac{1}{N}\sum_{i=1}^{N} \left(x_i - y_i\right)^2 ,
\]
où $x_i$ et $y_i$ sont les échantillons (tous canaux et instants confondus) des
deux signaux nettoyés et $N$ leur nombre total. Seuls les essais communs aux
deux signaux (gauche/droite, repos exclu) sont comparés.

\subsection{Évolution du MSE pendant l'entraînement (LOSO)}
Le modèle de débruitage est évalué en \emph{leave-one-subject-out} : pour
chaque sujet, un modèle neuf est entraîné uniquement sur les autres sujets, puis
évalué (même MSE que ci-dessus) sur le sujet exclu, jamais vu pendant
l'entraînement. L'opération est répétée pour chaque sujet.

Pendant l'entraînement, on suit deux courbes : le MSE sur les données
d'entraînement et le MSE sur le sujet exclu, après chaque passage complet sur
les données (epoch). Un écart croissant entre les deux signale un
sur-apprentissage.
